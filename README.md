# 영어 단어 학습

브라우저에서 바로 여는 영어 단어 학습 페이지입니다. 카드로 뜻을 확인하고, 퀴즈로 복습할 수 있습니다.

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. **카드**에서 단어를 클릭하면 뜻과 예문이 나옵니다.
3. **알아요**를 누르면 그 단어를 아는 단어로 표시하고 다음으로 넘어갑니다.
4. **퀴즈**에서 영어 단어의 뜻을 고릅니다. 맞히면 예문이 나오고 진도에 반영됩니다.

아는 단어 수는 브라우저에 저장되므로, 같은 브라우저에서 다시 열면 진도가 유지됩니다. **진도 초기화**를 누르면 저장된 기록을 지웁니다.

키보드로도 카드를 넘길 수 있습니다.

- 스페이스 또는 Enter: 뜻 보기 / 숨기기
- 왼쪽 / 오른쪽 화살표: 이전 / 다음 단어

## 단어 추가

`index.html`의 `WORDS` 목록에 아래 형식으로 한 줄을 추가합니다.

```js
{ en: "apple", ipa: "/ˈæp.əl/", ko: "사과", ex: "I eat an apple every morning." }
```

- `en`: 영어 단어
- `ipa`: 발음 기호
- `ko`: 한국어 뜻
- `ex`: 예문
